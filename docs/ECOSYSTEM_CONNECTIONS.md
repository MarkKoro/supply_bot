# Связанные сценарии продуктов

Канонический контракт: [Progressor Core / ECOSYSTEM_CONNECTIONS](https://github.com/MarkKoro/progressor_core/blob/main/docs/ECOSYSTEM_CONNECTIONS.md).

В существующем native меню «Связь продуктов» доступен «Сегодня вместе»; renderer и единственное меню сохраняются. WebApp загружает один общий интерфейс из Core. Просмотр не вызывает ИИ или уведомлений. Базы, история, цели, дозы и платёжные данные принадлежат своим продуктам. Отдых не останавливает оплаченный срок.

Общий день показывает только свои свежие разрешённые данные. Food — день Москва UTC+3; Supply — собственный часовой пояс. Полная и свободная поверхность Gym учитываются без дублей; незавершённая тренировка не вызывает post-workout push. Записанная еда/подтверждённый день прекращают прежнее напоминание, не доказывая достаточность питания. При изменении общих обработчиков обновлять canonical Core и все копии, тестировать и публиковать обычным FF в main.
